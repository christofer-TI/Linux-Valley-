# Dovecot

## Objetivo

Este laboratorio tem como objetivo aprender a instalar, configurar e administrar o Dovecot em um servidor Linux, entendendo seu funcionamento como servico de acesso as caixas de e-mail.

## O que é o Dovecot?

O Dovecot é um servidor de e-mail utilizado para disponibilizar mensagens armazenadas aos usuarios por meio dos protocolos IMAP e POP3.

Neste laboratorio, o foco sera ao protocolo IMAP, permitindo acessar e consultar mensagens armazenadas no servidor.

## Conteudo estudado

- Instalacao do Dovecot.
- Configuracao inicial do servico.
- Configuracao do armazenamento de mensagens.
- Conhecendo os arquivos de configuracao.
- Autenticacao de usuarios.
- Configuracao do protocolo IMAP.
- Verificacao de logs.
- Testes de funcionamento.

## Arquivos do laboratorio

- configs/10-auth.conf.example: configurações de autenticação.
- configs/10-mail.conf.example: configurações de armazenamento das mensagens.
- configs/10-master.conf.example: configurações dos serviços e portas.
- configs/10-ssl.conf.example: configurações de segurança TLS.

## Resultado esperado

Ao finalizar o laboratorio, compreender o funcionamento basico do Dovecot, configurar o acesso as caixas postais utilizando IMAP e realizar testes de autenticacao e leitura de mensagens
